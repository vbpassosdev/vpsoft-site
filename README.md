# VPSoft Site

Site institucional simples da VPSoft, criado com Next.js, TypeScript e Tailwind CSS.

## Conteudo

- Apresentacao da empresa
- Secao "Quem somos"
- Biografia de Vanessa Passos
- Chamada de contato

## Desenvolvimento

Instale as dependencias:

```bash
npm install
```

Rode o servidor local:

```bash
npm run dev
```

Acesse `http://localhost:3000`.

## Scripts

```bash
npm run dev
npm run build
npm run start
npm run lint
```
